01 · 产品介绍

从数据导入到洞察输出的 AI 分析闭环

安永数智助手（EY intelligent DA Client）将自然语言需求、Dify 工作流、Python 分析代码、本地数据执行和结果看板整合在一个桌面端产品中。它既服务财审数据核查，也支持业务与财务趋势、异常、变化的快速分析。

01
自然语言驱动
用户用中文或英文描述分析目标，系统将问题、数据结构、字段样例和关系证据发送至 Dify，由工作流规划需求并生成 Python 分析代码。
02
数据本地化处理
数据文件导入后在本机完成预处理、缓存、代码校验、样本预跑和完整执行。原始数据处理留在本地桌面端，降低反复传输与外流风险。
03
结果优先体验
结果面板集中展示摘要、指标、表格、图表、洞察与告警；用户可在执行前审阅代码，也可在失败后触发修复流程，让分析透明可控。
DA
数据分析
支持经营分析、财务趋势分析、异常波动解释、同比环比、分组汇总、指标计算和图表生成，适合从数据维度分析业务与财务变化。
自然语言 图表结果
MF
多文件联合分析
可同时选择多个数据集，按业务主键、期间、客户、科目等维度进行跨表关联、对比、补充和校验，支持更复杂的财审分析场景。

CL
数据清洗
面向缺失值、重复值、空白行、空字段和格式不一致等问题，提供独立清洗入口和单目标数据集处理流程。

02 · 适用场景

覆盖内部赋能与外部交付的 双场景

同一套工具既可以服务内部财审与数据分析团队，也可以作为客户项目中的轻量化、可部署、可演示的数据分析解决方案。

INTERNAL
内部使用场景
  • 支持财审团队进行底稿数据核查、异常筛选、波动解释、趋势对比和明细穿透，减少重复性 Excel 操作。
  • 财审人员可自行导入财务数据，用自然语言提出分析问题，快速获得指标、表格、图表和初步洞察。
  • 在项目支持中作为数据分析加速器，帮助团队更快完成字段理解、样本探索、跨文件核对和结果复核。
  • 沉淀可复用的 AI + 数据分析工作流，为后续行业场景、审计程序和自动化工具扩展打基础。
EXTERNAL
外部客户场景
  • 面向客户财务、运营、内控、合规等数据，提供灵活部署的数据分析助手，适配客户网络与安全要求。
  • 强调数据本地化处理：客户原始数据可保留在本地环境，AI 侧主要接收字段结构、样例和分析上下文。
  • 业务人员无需 IT 背景即可提出需求，例如按产品、区域、客户、期间分析收入趋势、成本变化、异常波动。
  • 在 PoC、专项分析、管理层汇报和审计科技展示中快速响应客户需求，形成可看、可试、可扩展的解决方案。

04 · 技术架构

Dify 生成逻辑，本地完成 可信执行

当前版本采用 PySide6 构建 Windows 桌面应用，结合 Pandas、DuckDB、PyArrow、Matplotlib 等数据处理能力。Dify 负责理解需求和生成代码，客户端负责数据画像、代码合同校验、本地执行、错误修复与结果渲染。

1
数据导入
支持 Excel 多文件导入，生成字段画像、样例值、数据集身份与本地缓存。
2
需求理解
将用户问题与压缩后的数据上下文发送至 Dify，形成分析计划与澄清选项。
3
代码生成
Dify 输出 Python 代码，遵循本地数据 API 与结果收集协议。
4
本地校验执行
客户端进行合同校验、样本预跑、子进程执行和异常修复。
5
结果呈现
输出摘要、指标、表格、图表、洞察、告警和执行细节，支持进一步分析。
Deploy
灵活部署：从公司内网 Dify 到外部网络环境
当前可接入公司内网 Dify Workflow；在客户项目或外部网络场景中，可复制同样的客户端 + Dify 工作流架构，替换 API 地址、密钥与模型服务，即可形成独立环境下的分析助手。原始数据处理仍可保留在本地桌面端，兼顾交付速度、数据边界和部署弹性。
